# Le banc des décisions

Déposer index.html à la racine du dépôt GitHub. Dans Settings > Pages, choisir Deploy from a branch, main, / (root), puis Save.

Application autonome : ouvrir index.html dans un navigateur pour jouer hors connexion. Version à trois réponses A/B/C validée le 25 novembre 2026.

Avant publication publique, vérifier les droits des images et logos et les autorisations relatives aux éventuelles photos de joueurs mineurs.
